### 3. Claude Code: Hooks, Subagents, and Skills — Complete Guide

**URL:** https://ofox.ai/blog/claude-code-hooks-subagents-skills-complete-guide-2026/
**Time:** ~4 min read
**Category:** Power User Extensibility

**Why it's relevant:** This is the "graduate-level" guide to Claude Code's three extensibility layers. **Skills** are reusable prompt templates (you already know `/standup` from a previous digest — now create `/client-brief`, `/data-profile`, `/weekly-report`). **Hooks** are deterministic scripts that fire on events like session start or tool calls — use them to enforce rules that must work 100% of the time (auto-lint, auto-test, auto-format). **Subagents** are parallel workers with their own context windows — spin up 3 subagents to handle independent parts of a deliverable simultaneously. The key insight: skills are guidance (~80% compliance), hooks are deterministic (100%), subagents are delegation.

**Key Takeaway:** Start with skills for your top 3 recurring consulting tasks. Add a hook for anything that must happen every time (e.g., "run pytest before committing"). Use subagents when a task naturally decomposes into independent pieces. This three-layer approach is how power users get 3x more from Claude Code.

## Quick Win: Set Up a Pre-Commit Hook

Add this to your project's `.claude/settings.json` today — it takes 60 seconds and prevents broken commits:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash(git commit)",
        "hook": "#!/bin/bash\necho 'Running pre-commit checks...'\npython -m pytest tests/ --tb=short -q 2>/dev/null || echo 'Warning: tests failed'\npython -m ruff check . --fix 2>/dev/null || true"
      }
    ]
  }
}
```

This fires automatically every time Claude tries to `git commit` — it runs your tests and linter first. Unlike CLAUDE.md instructions (which Claude might skip), hooks execute deterministically. You'll never push broken code from a Claude session again.
