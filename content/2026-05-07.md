## Resource 2: Claude Code Tips I Wish I'd Had From Day One

**Source:** [Claude Code Tips I Wish I'd Had From Day One — Marmelab](https://marmelab.com/blog/2026/04/24/claude-code-tips-i-wish-id-had-from-day-one.html)
**Time:** ~5 min read
**Category:** Workflow — Sharpen the Fundamentals

### Why This Is Relevant

You've been using Claude Code daily for 8+ weeks and building advanced skills. But advanced users often have blind spots in fundamentals — habits from early usage that were never revisited as the tool evolved. This article, published April 24, 2026, is written by a developer who compiled their "wish I'd known this sooner" list after months of daily use. It's the type of resource that surfaces one or two techniques you've been doing the hard way.

**Key techniques to check against your workflow:**

- **Session retros:** The article recommends asking Claude "What did you learn during this session?" at the end of each session and saving the output to CLAUDE.md, rules files, or skill definitions. You've been building knowledge into your `/reverse-engineer` skill iteratively — but are you systematically capturing what Claude learns about your ISP codebase across sessions? Each session produces institutional knowledge that evaporates when the context window closes.
- **Plan mode discipline (Shift+Tab):** Use plan mode before any complex operation. For your pipeline, this means having Claude lay out its analysis approach before it starts reading files — catching wrong assumptions about cluster structure before implementation begins. Correcting a plan costs seconds; unwinding a half-finished 5-agent analysis costs minutes.
- **The `/simplify` pass:** After Claude generates code or skill definitions, run `/simplify` to strip over-engineering. Claude tends to add unnecessary abstractions, speculative error handling, and defensive generics. Your skill definitions may have accumulated this cruft across 38 iterations.
- **Preview-driven autonomy:** Using the browser preview lets Claude test its own changes and self-correct before you review. For your pipeline, this means Claude can validate its JSON output against your schema before presenting it as "done."

**The meta-principle:** This article's value isn't any single tip — it's the practice of periodically auditing your workflow against what others have discovered. After 38 digests of building increasingly advanced capabilities, spending 5 minutes on fundamentals is the highest-leverage investment you can make today.

### Key Takeaway

Run `/simplify` on your `/reverse-engineer` skill definition today. After 38 iterations of adding capabilities, the skill prompt likely contains redundant instructions, over-specified constraints, or accumulated phrasing that Claude doesn't need. A single `/simplify` pass will tighten it — less prompt means faster execution and fewer confused agent behaviors.

## Quick Win: Explore the Financial Services Agent Templates (5 min)

**Time: 5 minutes**

The 10 financial services agent templates shipped yesterday as Code plugins. They're the first official Anthropic-built agent templates for a regulated industry — and their architecture patterns (compliance hooks, audit trails, approval workflows) are directly transferable to consulting use cases.

**Step 1:** Check if the templates are available in the plugin marketplace:
```bash
claude plugin search financial-services
```

**Step 2:** Install one template to inspect its structure:
```bash
claude plugin install <template-name>
```

**Step 3:** Read the plugin's structure:
```bash
ls -la .claude/plugins/<template-name>/
cat .claude/plugins/<template-name>/plugin.json
```

**What you're looking for:**

- **How they structure multi-agent coordination** — compare their agent definitions to your 5-agent pipeline
- **What hooks they use for compliance** — these are enterprise-grade validation patterns you can adapt
- **How they handle audit trails** — every action traced and logged, which maps to your MLflow tracing setup
- **The Managed Agents cookbook patterns** — coordination, state management, error recovery

**Why now:** Yesterday you learned how to package your skill as a plugin. Today, study how Anthropic packages theirs. Their financial services templates are the reference implementation for enterprise-grade agent plugins. The gap between their patterns and yours is your improvement roadmap. Five minutes of reading their `plugin.json` will teach you more about production agent architecture than an hour of documentation.
