## Quick Win — Apply This Today

**Set up your CLAUDE.md file for consulting work.**

If you don't have one yet, create a `CLAUDE.md` in your main working directory with these sections:

```markdown
# Context
I am a BCG consultant. I use Claude Code for data analysis, automation, and scripting.

# Preferences
- Use Python with pandas for all tabular data work
- Output charts with matplotlib or plotly; use clean, presentation-ready styling
- When generating reports, use concise executive-summary style
- Default to CSV for data interchange unless told otherwise

# Project conventions
- Keep scripts in a /scripts directory
- Name output files with ISO dates: YYYY-MM-DD-description.ext
- Always include a brief summary comment at the top of analysis scripts
```

This takes 2 minutes and immediately improves every future Claude Code session by eliminating repetitive instructions. Claude reads this file automatically at the start of each session.
