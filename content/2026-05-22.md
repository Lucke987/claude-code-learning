## Quick Win: Start Every Project With `/init`

**Apply this today in under 2 minutes.**

Open any project repo in Claude Code and run:

```
/init
```

This auto-generates a `CLAUDE.md` file that persists across every future session. Add your project's:
- Build/test commands (so Claude can self-validate)
- Coding conventions and naming standards
- Key architectural decisions

The payoff: Claude stops asking you the same setup questions and starts producing correct output from turn one. For consulting projects where you context-switch between multiple clients, this is the single highest-ROI habit you can build.
