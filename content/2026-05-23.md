## Quick Win: Apply This Today

**Set up a `/standup` custom command for your projects.**

Create a file at `.claude/commands/standup.md` in your project with this content:

```
Review what was changed in the last 24 hours (git log --since="24 hours ago").
Summarize the current state of the feature branch.
List any failing tests or lint errors.
Suggest the top 3 things to tackle today based on recent momentum.
```

Then run `/standup` at the start of each work session. This replaces 5-10 minutes of manual context rebuilding and is especially powerful when you're switching between client engagements. You'll get an instant briefing on where you left off.
