### 1. Claude Code Routines: Automated Tasks Without Leaving Your Computer On

**URL:** https://www.mindstudio.ai/blog/claude-code-routines-scheduled-cloud-tasks
**Time:** ~5 min read
**Category:** Cloud Automation

**Why it's relevant:** Routines are the biggest Claude Code feature you haven't used yet. They run on Anthropic's cloud infrastructure — your laptop can be closed. Three trigger types: **Scheduled** (daily, weekly, hourly), **API** (trigger via HTTP POST from any tool — Zapier, n8n, a Slack bot), and **GitHub** (auto-run on PRs, releases, or issues). For consulting, the use cases are immediate: schedule a Monday morning routine that pulls the latest data from a client repo, runs analysis, and commits a summary report — all before you open your laptop. Or trigger a routine via API whenever a client updates a shared Google Sheet. Pro plan gets 5 routines/day, Max gets 15. The article walks through setup, configuration, and real examples.

**Key Takeaway:** Set up one scheduled routine this week for your most repetitive task — a daily data pull, a weekly status report, or a nightly test suite run. Routines turn Claude Code from "assistant you talk to" into "worker that runs while you sleep."

## Quick Win: Create Your First Routine

**Apply this in 5 minutes from claude.ai/code:**

1. Go to **claude.ai/code** → **Routines** (in the sidebar)
2. Create a new routine with:
   - **Name:** `weekly-status`
   - **Repo:** Your most active client project
   - **Prompt:**
     ```
     Analyze the git log from the past 7 days. Summarize:
     1. Features completed (with PR links if available)
     2. Bugs fixed
     3. Work in progress (open branches)
     4. Key metrics (lines changed, files modified, test coverage delta)
     Format as a concise executive summary suitable for a client status email.
     Commit the report to docs/weekly-status/YYYY-MM-DD.md.
     ```
   - **Trigger:** Scheduled → Weekly → Monday 7:00 AM

3. That's it. Every Monday morning, a status report will be waiting in your repo before you start work.

**Why this matters:** Consultants spend 30-60 minutes every week assembling status updates. A routine does it in 2 minutes of compute time, with zero manual effort, and the output is version-controlled and auditable.
